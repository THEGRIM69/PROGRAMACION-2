# SystemAnalyzer

Aplicación de escritorio académica para analizar el sistema operativo y el rendimiento de un equipo Windows.

## Estado

Fase 1 completada: estructura base, arquitectura, ventana principal y navegación.

## Abrir y ejecutar

1. Abra `SystemAnalyzer.sln` con Visual Studio 2022.
2. Espere a que Visual Studio restaure el proyecto.
3. Presione `F5` o el botón **Iniciar**.

También puede compilar desde una terminal con `dotnet build SystemAnalyzer.sln`.
